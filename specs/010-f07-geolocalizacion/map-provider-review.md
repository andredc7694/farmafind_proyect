# F07 — Revisión del proveedor de mapa TEST/DEMO

**Fecha:** 2026-11-18. **Alcance:** documentación y desarrollo local de bajo volumen; no constituye aprobación productiva ni prueba de tráfico real.

| Control | Evidencia oficial | Decisión F07 |
| --- | --- | --- |
| Visor | [Leaflet, licencia BSD-2-Clause](https://github.com/Leaflet/Leaflet/blob/main/LICENSE). Su licencia no cubre las teselas. | Leaflet es candidato compatible; instalación/versión se decidirán al implementar y revisar dependencias. |
| Fuente de teselas | [OSMF Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/) exige URL HTTPS oficial, atribución visible, referer, caché conforme a cabeceras y prohíbe descarga masiva/precarga/offline. No ofrece SLA y puede limitar acceso. | Las teselas OSM estándar son candidatas únicamente para visualización interactiva humana y TEST/DEMO de bajo volumen. No se precargan, no se usan en pruebas automatizadas de barrido y la lista funciona sin ellas. |
| Licencia de datos | [OSM Copyright](https://www.openstreetmap.org/copyright) exige atribución y referencia ODbL. | Mostrar crédito visible «© OpenStreetMap contributors» y enlace de licencia; conservarlo en móvil y escritorio. |
| Privacidad | [OSMF Privacy Policy](https://osmfoundation.org/wiki/Privacy_Policy) describe registro de datos de acceso, incluidas IP y solicitudes de teselas; la política de teselas prohíbe enviar datos personales/confidenciales. | El mapa se carga solo después de una acción informada. Se centra inicialmente en farmacias públicas o ciudad, no en la coordenada personal precisa; no se envía posición personal como parámetro de rutas ni a teselas. Se informa que OSMF recibirá IP y área visible. |
| Costos y cobertura | OSMF no exige clave/API pagada para uso modesto sujeto a su política, pero no garantiza disponibilidad ni uso ilimitado. La cobertura local y carga de teselas aún no se han probado. | No se habilita facturación ni proveedor comercial; si la cobertura o política falla, mapa bloqueado y lista operativa. La aceptación completa exige comprobar la experiencia real. |

**Resultado T002/T030:** revisión documental aprobada para una implementación TEST/DEMO con carga voluntaria. Se instaló [Leaflet 1.9.4](https://www.npmjs.com/package/leaflet?activeTab=versions). La implementación usa solo teselas oficiales `https://tile.openstreetmap.org/{z}/{x}/{y}.png` tras clic informado, crédito visible y sin precarga. Los tests automatizados bloquean solicitudes de teselas; no prueban cobertura ni disponibilidad real del proveedor. Despliegue productivo exigiría nueva revisión de volumen, privacidad y proveedor. La inferencia de que el área visible puede revelar ubicación aproximada proviene de las teselas solicitadas, no de una declaración textual de OSMF.

**Revisión del 2026-11-18:** la [política oficial de teselas](https://operations.osmfoundation.org/policies/tiles/) continúa exigiendo URL HTTPS, atribución visible, `Referer` web y caché conforme a cabeceras; prohíbe descargas masivas y no ofrece SLA. La [licencia ODbL y atribución](https://www.openstreetmap.org/copyright) y la [política de privacidad](https://osmfoundation.org/wiki/Privacy_Policy) continúan pertinentes. No se autoriza uso productivo con esta revisión TEST/DEMO. En la auditoría npm de esta fecha, tanto el árbol completo como `--omit=dev` reportaron **0** vulnerabilidades; las cinco alertas históricas no deben presentarse como resultado actual.

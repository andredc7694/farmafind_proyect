# Numeración histórica: antiguo F07 AWS

Los archivos de esta carpeta son un **borrador histórico no aprobado** del antiguo incremento F07 — despliegue AWS, redactado antes de la adopción del Documento Maestro v3.0. Se conservan con su nombre, ruta y contenido originales para mantener la trazabilidad. No autorizan crear recursos ni realizar despliegues.

Desde la ratificación de la Constitution v1.2.0 el 2026-11-17, **F07** designa geolocalización y **F09** designa el futuro despliegue AWS manual y supervisado. En la [matriz de adopción](../../docs/roadmap-v3-adoption.md), esta carpeta se identifica como `F07-LEGACY-AWS` → F09. Su prefijo de directorio `008-` es un número secuencial de Spec Kit, no el ID funcional F08.

La futura especificación F09 tendrá que elaborarse y aprobarse por separado. La arquitectura y las decisiones históricas se conservan como antecedente; los pasajes de este borrador que sugieran automatizar infraestructura no sustituyen la regla vigente de autorización humana por recurso, configuración, costo y operación facturable.

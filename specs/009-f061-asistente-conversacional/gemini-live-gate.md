# Puerta para prueba de desarrollador Gemini F06.1

**Revisado:** 2026-11-17. **Estado:** preparado y bloqueado; cero solicitudes reales. El proveedor activo de FarmaFind sigue siendo `MockConversationProvider`. El adaptador Gemini y el ejecutor de prueba no están conectados a las rutas públicas.

## Modelo y términos verificados

- **Candidato, pendiente de aprobación:** [`gemini-3.5-flash-lite`](https://ai.google.dev/gemini-api/docs/models), modelo estable listado para proyectos nuevos. El adaptador actual usa el endpoint REST `v1beta/models/{model}:generateContent`; la [documentación de GenerateContent](https://ai.google.dev/api/generate-content) describe `usageMetadata`. La compatibilidad del modelo con este adaptador no se afirma por simulación: solo una prueba real autorizada la confirmará. No se reemplaza el adaptador ni se instala SDK.
- [Precios](https://ai.google.dev/gemini-api/docs/pricing): el modelo figura con entrada y salida gratuitas en el nivel Free, sujeto a disponibilidad y cuota del proyecto. [Límites](https://ai.google.dev/gemini-api/docs/rate-limits): RPM, TPM y RPD varían por modelo/proyecto y se consultan en AI Studio; no se inventa una cuota numérica. El responsable debe comprobar allí que el proyecto y la clave están en **Free Tier sin facturación activa** antes de ejecutar.
- [Claves API](https://ai.google.dev/gemini-api/docs/api-key): crear una clave propia en Google AI Studio para un proyecto separado. Se necesita credencial de backend; no se coloca en React, Git, capturas ni documentación. No se crea proyecto, clave ni facturación en este trabajo.
- [Términos vigentes](https://ai.google.dev/gemini-api/terms): en el nivel gratuito Google puede usar entradas y salidas para mejorar productos y revisarlas humanamente; prohíbe enviar información sensible, confidencial o personal. También restringe clientes accesibles a menores y el uso para consejo médico o práctica clínica. Por tanto esta prueba se limita a un desarrollador adulto y preguntas sintéticas. **No habilita Gemini en el asistente público de FarmaFind**; esa integración exigiría resolver por separado la compatibilidad del producto con los términos, la privacidad y las reglas clínicas.

## Límites implementados para la prueba aislada

El script `scripts/f061/run-gemini-live.mjs` requiere aprobación literal de modelo/privacidad/límite, confirmación Free Tier y clave en el proceso backend. Envía como máximo **3 solicitudes HTTP** totales, incluso contando un reintento transitorio; ejecuta una sola consulta a la vez; cada intento expira en **5 segundos**. El adaptador limita el texto a 500 caracteres, la salida solicitada a **100 tokens**, y detiene nuevas consultas al alcanzar **1 000 tokens totales informados**. Si falta `usageMetadata` o hay error, bloquea el resto de la prueba. Un límite de respuesta no garantiza por sí solo el consumo total de entrada o pensamiento; el límite de solicitudes y la revisión posterior de tokens siguen siendo necesarios.

Solo se envían tres frases fijas sobre búsqueda, datos públicos y comparación; no se envían datos de usuarios, farmacias ni conversaciones reales. La pregunta farmacológica de molestias queda registrada como `blocked-no-reviewed-source` y **no sale a Gemini**. El script imprime número de solicitudes, tokens informados, estados e intenciones, nunca clave, texto de consulta ni respuesta. No almacena conversaciones. El fallback determinista se prueba con transporte simulado y permanece inactivo en las rutas públicas.

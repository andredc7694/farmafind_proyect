# Frontend F00

React + Vite + JavaScript/JSX muestran únicamente “FarmaFind — Bootstrap”. La pantalla no consulta API ni inventario, no presenta farmacias o medicamentos y no usa datos personales. El único valor público de configuración es `VITE_APP_MODE=bootstrap`; perfiles y puertos del lanzador permanecen fuera del bundle.

Los siete módulos históricos y FarmaFind AI futura conservan sus límites documentados en el núcleo. PostgreSQL/RLS, Redis, Unit of Work/Outbox, Docker Compose y AWS S3 privado/CloudFront OAC/Lightsail corresponden a etapas posteriores. No existe integración operativa ni agente IA que diagnostique, prescriba o recomiende dosis. Se conservan requisitos y ADR históricas; RC04 y ADR complementarias siguen pendientes.
